# Umthombo Creations — Website Build Brief & Roadmap

A complete handoff document for Claude Code. The goal is a **bespoke, editorial, animated** website for a real Cape Town handcrafted-candle & skincare business — one that feels *authored by a designer*, not assembled by a template or generated by AI.

> **Umthombo** means *"spring"* or *"fountain"* — a source of renewal and flow. That single idea is the spine of the entire design.

---

## 0. The one rule above all others

This site must **not** look like a demo, a Shopify theme, or "AI slop." That means we deliberately avoid every default:

- ❌ No Inter / Roboto / system-font stacks. No centered hero + three feature cards + purple gradient.
- ❌ No stock "3 cards in a row" everywhere, no glassmorphism, no generic SaaS layout, no emoji headers.
- ✅ Instead: an **earthy, editorial, hand-made** aesthetic with asymmetry, organic shapes (the brand already uses blobs), real photography, paper grain, generous negative space, and motion that *means something* (liquid rising, wax glow, reeds swaying).

Everything below serves that rule.

## 2. Creative concept — *"The Source"*

Build the whole experience around water rising from a spring: **calm → flow → warmth.**

- **Motion language:** slow rises, gentle liquid sway, soft warm flicker. Nothing snappy or techy. Everything breathes.
- **Texture:** subtle paper/linen grain overlay across the site (a faint noise PNG or SVG turbulence at ~3–5% opacity) so it feels printed and handmade, never flat-digital.
- **Shape language:** the organic **blobs** already in the deck become a recurring device — section dividers, image masks, hover backdrops. Use fluid `border-radius` and SVG paths, not perfect circles.
- **Voice:** warm, grounded, unhurried, South African. "Made with love and inspired by nature." First-person plural ("we"). Never corporate.

## 3. Art direction

### 3.1 Colour (extracted from the deck — use as CSS variables / Tailwind theme)

```css
/* Core palette */
--clay:    #A6402C;  /* terracotta / rust — primary brand, the "U" mark, headings */
--olive:   #6E8C3C;  /* sage-olive — Home category, growth, secondary actions   */
--mist:    #91AECA;  /* dusty blue — Hampers, calm, tertiary                     */
--taupe:   #97897A;  /* warm mushroom — Candle category surfaces                 */
--cream:   #FAF6ED;  /* warm paper — default background                          */
--ink:     #2A2420;  /* near-black warm charcoal — body text                     */
--cream-2: #F0E9DA;  /* slightly deeper paper for cards/sections                 */
```

**Usage rule:** dominant cream + ink, with **clay as the hero accent** and olive/mist/taupe used to *colour-code the three categories* (Home = olive, Body = clay, Skin = clay-warm, Hampers = mist). One dominant accent per section beats an evenly-distributed rainbow.

### 3.2 Typography (this is what kills the "AI look" fastest)

- **Display / headings:** **Fraunces** (variable Google font). High-contrast, soft, characterful, editorial — matches the serif in the deck but with more soul than Playfair. Use the `opsz` (optical size) + `SOFT` axes; tighten tracking on large sizes.
- **Body / UI:** **Hanken Grotesk** (or **Geist** as alternate). A warm, humanist grotesk — clean but not sterile like Inter.
- **Accent / labels:** Fraunces *italic* for editorial captions and pull-quotes. Use small-caps + wide tracking for category eyebrows.
- Load via `next/font/google` with `display: 'swap'`. Set fluid type with `clamp()`.

### 3.3 Layout principles

- **Asymmetry by default.** Off-center heroes, text that overlaps imagery, products that break the grid.
- **Editorial product layout** mirroring the deck: large image on one side, generous whitespace, big serif name, small spec block, single quiet call-to-action. Alternate left/right down the page.
- **Big type, small UI.** Product names huge; metadata small and calm.
- **A 12-col grid you're allowed to break.** Pull images into the margin, let headings bleed.

### 3.4 Imagery

- The catalogue already contains product photography on wood/raffia — that warm, natural styling **is** the brand. Plan for `next/image`, rounded organic masks, subtle parallax, and a gentle zoom-on-hover.
- Until real exports are dropped in, use tasteful neutral placeholders at the **same aspect ratios** and same warm tones — never bright stock photos.

## 5. No payments — the Order flow (important)

There is **no checkout/payment**. Replace every "Buy" with **"Order"** / **"Add to Order"**. Two pieces:

### 5.1 The Cart (a beautiful slide-over, not a page)

- A right-side **drawer** ("Your Selection") that slides in with a soft spring, dims the page behind with a warm overlay, and animates line items in/out with Motion `layout` + `AnimatePresence`.
- Each line: thumbnail (organic-masked), name, variant/scent, qty stepper, line price in **ZAR (R)**, remove (x).
- Footer: subtotal, the **10% reusable-container note** ("Bringing your own jar? Mention it — 10% off."), and a primary **"Place your order"** button.
- Empty state has personality: a small line-drawn fountain + "Your selection is still a quiet spring." (on-brand, not "Cart is empty").
- Cart count badge animates (pop) when an item is added. Persist to localStorage via Zustand.

### 5.2 The Order modal (collects details)

On "Place your order" → centered **modal** with a multi-step feel (or one calm form):

**Fields (validated with Zod):**
- **Name** (required)
- **Email** (required, valid email)
- **Phone** (required, ZA format friendly: `+27` or `0…`)
- Optional: delivery vs. **collection in Observatory** toggle, optional note ("personalisation, scent, colour…").

**On submit — choose ONE primary mechanism (recommended order):**

1. **WhatsApp deep-link (recommended MVP, zero backend keys):** build a pre-filled message to **+27637053286** summarising the order + customer details and open `https://wa.me/27637053286?text=<encoded summary>`. This matches how the business already operates. Show a success screen ("We've opened WhatsApp with your order — hit send and we'll be in touch 🌱" — keep emoji optional/minimal).
2. **Email via Resend (enhancement):** a `POST /api/order` route using the **Resend** SDK to email the owner the full order. Add `RESEND_API_KEY` to `.env.local`. Return success/fail to the modal.
3. *(Optional later)* mirror to a Google Sheet / Airtable for record-keeping.

> Build #1 first so it works with no secrets, then layer #2 behind a feature flag / env check.

Success state should feel handcrafted (animated fountain "fills," confetti is too generic — use a gentle rising-bubbles or wax-glow animation instead).

## 7. Animation & interaction spec

High-impact, themed, never gratuitous:

- **Page load:** one orchestrated staggered reveal (hero wordmark → tagline → image glow → blob). `staggerChildren`.
- **Scroll reveals:** sections fade + rise slightly (y: 24 → 0) with `whileInView`, once.
- **The fountain motif:** SVG line-draw on the logo flourish; subtle rising-bubble particles in hero and order success.
- **Candle glow:** featured candle images get a soft, slow-pulsing radial glow (CSS `@keyframes`, very subtle).
- **Reed sway:** diffuser/Home imagery gets a slight rotate oscillation.
- **Product hover:** organic mask morph + 1.03 zoom + name underline draw.
- **Cart:** drawer spring-in, line items `layout`-animate, count badge pop.
- **Smooth scroll:** Lenis site-wide; respect `prefers-reduced-motion` everywhere (gate all of the above).
- **Custom cursor (optional, tasteful):** a small soft dot that grows over interactive elements. Skip on touch.

Keep durations slow (0.5–0.9s) and easings soft (`ease: [0.22, 1, 0.36, 1]`).

## 9. Data model & helpers

- `formatZAR(n)` → `R75.00` (use `Intl.NumberFormat('en-ZA', { style:'currency', currency:'ZAR' })`).
- Cart item = `{ slug, name, variant?, qty, unitPriceZAR }`.

## 10. Accessibility, performance, SEO

- **A11y:** Radix-based Dialog/Sheet (focus trap, ESC, ARIA). Colour contrast AA on cream. All interactive elements keyboard-reachable. `prefers-reduced-motion` gates every animation.
- **Perf:** `next/image` everywhere, font subsetting via `next/font`, lazy-load below-the-fold, Lenis only on non-reduced-motion. Target Lighthouse ≥ 95.
- **SEO:** per-route `metadata`, OpenGraph image, `JSON-LD` `Product` schema on product pages, sitemap + robots. Local-business schema with Cape Town / Observatory.
